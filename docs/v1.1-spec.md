## F1 黄历模块契约

### 文件：`src/almanac.js`

UMD 模块，同时支持 `require('./almanac.js')` 与浏览器 `<script>` 全局 `Almanac`。
依赖 `lunar-javascript`（MIT）。在 Node 下直接 `require`；浏览器下通过 `window.LunarSolar` 取得 `Solar`（打包时内联）。

对外 API：

```js
// 指定日期返回黄历数据
Almanac.of(date) -> {
  ymd: '2026-11-06',
  weekday: '星期五',
  // 农历
  lunar: { year: '二〇二六', monthCn: '九', dayCn: '廿八', isLeap: false, text: '九月廿八' },
  ganZhi: { year: '丙午', month: '戊戌', day: '甲申' },
  shengXiao: '马',
  // 宜忌：字符串数组，已去重
  yi: ['嫁娶', '订盟'],
  ji: ['开市', '安床'],
  // 黄道吉日
  tianShen: '金匮',        // 值神
  tianShenType: '黄道',     // 黄道 / 黑道
  luck: '吉',              // 吉 / 凶
  zhiXing: '开',           // 建除十二神
  xiu: '鬼',               // 二十八宿
  chong: '冲虎',           // 冲煞描述（已完成格式化）
  sha: '煞南',
  // 节气与节日
  jieQi: '立冬' | null,     // 当天若为节气则给出
  festivals: ['国庆节'],    // 公历+农历节日合并
  // 一句「今日寄语」，结合宜忌生成，见下方规则
  tip: '今日宜「出嫁」，不宜「开市」，量力而行。'
}

// 未来 N 天（含今天）的简表，用于「最近吉日」
Almanac.upcoming(date, days) -> [{ ymd, weekday, dayCn, luck, tianShen, yi: top3, ji: top3, jieQi, festivals }]

// 通俗化：把黄历术语转成打工人能看懂的话
Almanac.humanize(term) -> '适合干的事' | 原词

// 今日运势评分（0-100），用于进度条/徽标
Almanac.score(almanacData) -> number
```

### 展示规则（`src/index.html` 新增卡片）

- 卡片标题：「今日黄历」
- 第一行：农历日期 + 干支 + 生肖，右侧黄道/黑道徽标（吉=暖绿，凶=灰）
- 第二行：`宜` 三个标签（暖色），`忌` 三个标签（冷灰）
- 第三行：节气/节日（有才显示）
- 第四行：一句 `tip`
- 可折叠「看看最近几天」→ 展开 7 天简表
- 迷你悬浮窗内**不显示**黄历（保持 250×132 的紧凑）

## F2 安装/卸载闭环契约

- 打包命令改为 `electron-builder --win nsis portable --x64`，`nsis` 段已配置好，无需改。
- 产物命名：`WorkEncourager-Setup-${version}.exe`
- 必须有 `uninstallDisplayName`、开始菜单卸载快捷方式、控制面板卸载项。
- CI 的 `release.yml` 已正确（nsis + portable），本地 `npm run dist` 需同步改为带 `portable`。
- **验证标准**：`Setup-*.exe` 内含 NSIS 特征串（`Nullsoft` + `Uninstall`），安装后有 `Uninstall 牛马鼓励器.exe`。

## F3 测试脚本契约

`package.json` 的 `test` 脚本改为 `node --test test/*.test.js`（Windows 下 Node 24 不接受目录参数）。

## 代码风格

- 锁文件 ESLint 规则：ES5 风格函数、`var`、分号、IIFE 包裹（与现有 `earn.js` / `app.js` 一致）
- 不用 TypeScript、不用构建步骤，`src/` 直接可跑
- 所有新增文件都要有文件头注释说明职责
