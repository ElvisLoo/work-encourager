# 牛马鼓励器 · 上班鼓励器

> 把每一个工作日的每一秒，折算成屏幕上看得见的进账。
> 看见钱在长，班就没那么难上。

11 月初「上班鼓励器 / 牛马鼓励器」在网上火了，但流传的版本大多是网页或某单一平台的成品。
这个项目把它做成一个**跨平台桌面小工具**：Windows 装上即用，macOS / Linux 也能跑，同时保留一个**单文件网页版**，双击就能用。

全部本地运行，不联网、不上传、不需要账号。

## 功能

**核心**

- 实时滚动的「今日已到账」，金额精度可选 2 / 3 / 4 / 6 位小数（默认 4 位，像 `¥363.8222`）
- 下班倒计时，精确到秒；进度条与工时进度同步
- 每秒 / 每分钟 / 每小时 / 今日满勤四档速率，一眼看清自己一分钟值多少钱
- 午休、晚饭时段自动停表，休息结束无缝续算（支持跨零点班次）
- 本月累计：已过工作日按满勤计，再加上今天的实时进度
- 夜班友好：22:00 上班、次日 06:00 下班，凌晨时段也接着前一晚那班累计，不会归零

**打卡战报**

- 每天自动记一笔，形成本月的打卡日历（按真实星期排布，周末位置对得上）
- 本月到手、出勤天数、日均、最高一天四项统计
- 连续打卡天数，断了会重新数
- 颜色越深代表那天进账越多，格子悬停能看到具体金额

**今日黄历**

- 农历日期、干支、生肖，黄历术语已译成白话（嫁娶→结婚、开市→开张/启动新项目）
- 当天宜忌各取前三条，与职场无关的条目（安葬、破土等）不会出现
- 黄道吉日 / 黑道日一目了然，配一句「今日宜…不宜…」
- 可展开最近 7 天，挑个顺眼的日子谈加薪
- 节气与节日：立冬、春节这类日子会标出来

**情绪价值**

- 「这笔钱能换」——矿泉水、地铁、瑞幸、肉夹馍、炸鸡、电影票、一天房租，实时显示能换几件
- 「今日小目标」——耳机、手机、MacBook、旅行，显示还差多久能拿下（今天干完 / 还要 N 天）
- 一句随机的领班发言，看不下去的时候点一下换一句

**工位友好**

- 一键打码：所有金额模糊化，只留进度和倒计时，老板路过也安全
- 迷你悬浮窗：250×132，置顶、可拖动、可缩放，双击回到主面板
- 系统托盘常驻，关闭窗口不退出，托盘提示实时显示今日金额
- 开机自启（可选），启动后静默进托盘

**数据**

- 配置与打卡记录只存本机 `localStorage`，零网络请求
- 导出 JSON 时连打卡记录一起带走，换电脑直接恢复
- 支持导出 / 导入 JSON 配置（换电脑时直接搬过去）

## 快速开始

### 方式一：装好就用（Windows）

到 [Releases](../../releases) 下载：

- `WorkEncourager-Setup-x.y.z.exe` — 安装版，可创建桌面与开始菜单快捷方式
- `WorkEncourager-Portable-x.y.z.exe` — 便携版，不写注册表，放 U 盘里也能跑

> Windows SmartScreen 可能提示「未知发布者」，因为安装包没有代码签名。点「更多信息 → 仍要运行」即可。

### 方式二：直接用网页版

打开 `src/index.html` 就行，无需安装、无需服务器。也可以把它丢到任意静态托管上。

### 方式三：从源码跑

```bash
npm install
npm start          # 启动桌面应用
npm test           # 跑计薪内核单元测试
npm run dist       # 打 Windows 安装包到 release/
```

## 计薪口径

所有数字都是**估算**，用你自己填的薪资和作息算出来的，不代表实际结算：

```
每天计薪分钟 = (下班 − 上班) − 午休时长 − 晚饭时长
每日预计收入 = 月薪 ÷ 每月工作日
每分钟收入   = 每日预计收入 ÷ 每天计薪分钟
今日已挣     = 每分钟收入 × 今日已计薪分钟（精确到毫秒）
```

几点说明：

- 金额按毫秒连续累加，所以数字是平滑滚动的，不会每秒跳一下
- 「每月工作日」默认 21 天，双休一般 21～22 天，单休按实际填
- 本月累计里的「已过工作日」按周一到周五粗算，节假日和调休不自动识别——这个工具不打算管这么细，你自己心里有数就行

## 目录结构

```
.
├── src/
│   ├── main.js        # Electron 主进程：主窗口 / 托盘 / 迷你窗 / 开机自启 / 导出
│   ├── preload.js     # 最小 IPC 桥，渲染层拿不到 Node 能力
│   ├── index.html     # 界面结构（同时是网页版入口）
│   ├── styles.css     # 米色纸张 / 深咖暖金双主题
│   ├── app.js         # 渲染、交互、本地持久化
│   └── earn.js        # 纯函数计薪内核（可在浏览器与 Node 中复用）
├── test/earn.test.js  # 15 项单元测试
├── scripts/
│   ├── shot.js        # Electron 截图脚本（QA 用）
│   └── serve.js       # 网页版本地预览服务器
└── build/             # 图标资源
```

计薪逻辑全部集中在 `src/earn.js`，不依赖 DOM，可以单独引到别的项目里用：

```js
const E = require('./src/earn.js');
const cfg = { monthlySalary: 12000, workdaysPerMonth: 21, workStart: '09:00', workEnd: '18:00',
              lunchEnabled: true, lunchStart: '12:00', lunchEnd: '13:00' };
const c = E.compute(cfg, Date.now());
console.log(c.earned);      // 今日已挣
console.log(c.rates.perMin);// 每分钟多少钱
```

## 同类项目与灵感来源

做之前查了一圈，已有的实现大概这几类：

- [caseclose/work-encourager-open](https://github.com/caseclose/work-encourager-open) — 同名项目，Web + macOS 菜单栏原生应用，功能非常完整（番茄钟、班表、目标、提醒），MIT 许可
- [qiqichaoiwan/everydaysalary](https://gitee.com/nextvue/everydaysalary) — Gitee 上的 Python + Tkinter Windows 版，绿色气泡悬浮窗，按工作日计薪
- 各类浏览器扩展（Chrome 上实时薪资追踪）与微软商店里的「钱进」等成品

这个项目想补的位是：**Windows 上开箱可用 + 逻辑透明可读 + 单文件网页版兜底**。
计薪内核是几十行纯函数，想改口径直接改 `earn.js` 就行。
